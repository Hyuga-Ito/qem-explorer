# Decisions only the owner can make (QEM Explorer 1.7.0)

These were left open on purpose. Nothing in the release invents them; the placeholders say where they go.

| decision | where it goes | current state | what the release does meanwhile |
|---|---|---|---|
| **License** of the code (and, separately, of the data and figures) | a `LICENSE` file at the root, the `license` field of `pyproject.toml` and `CITATION.cff` | none chosen; the archive ships **without** a license, so by default others may not reuse it | the README says so; third-party licenses of the dependencies are untouched |
| **Authors and affiliation** | `CITATION.cff` (`authors`), `pyproject.toml` (`authors`), README | placeholder "QEM Explorer contributors" | no personal names or e-mail addresses are in the public archive |
| **Security contact** | `SECURITY.md` ("Reporting a vulnerability") | not set | `SECURITY.md` describes the protections and says that a contact is to be added by the owner |
| **Hardware validation run** | `configs/selection/hardware17.yaml`, `QEMX_HW_AUTHORIZE` | prepared, not executed | `hardware plan` writes the plan and its digest; execution is refused without the owner's authorization of that digest, a campaign ledger (one shared 600 s ceiling, 60 s reserve by default) and credentials from the environment, a saved account or a hidden prompt |
| **Running the larger study** (`full17.yaml`) | `python -m qemx.selection label configs/selection/full17.yaml …` | planned, not executed | `plan --measured reports/selection_v170/dev` gives ≈ 19.1 CPU-hours of labeling and ≈ 130 MB from the corrected pilot's measured rates (width 7 extrapolated), within its caps (80 CPU-hours, 10 GB); resumable and bound to its run |
| **Publishing** (GitHub repository, Streamlit Community Cloud, Zenodo) | — | nothing was pushed or published | the source ZIP is GitHub-ready; the two trial-data ZIPs are meant for release attachments or a data repository (33 MB of per-trial arrays would weigh on a Git history); the private audit ZIP is for the owner only |
| **Which bundle the app ships as default** | `qemx/selection/bundles/` | the frozen configuration's bundle (`qemx-rec-1.7.0`, needs simulated features) and a deployable-only bundle (`qemx-rec-1.7.0-deployable`, never simulates) are shipped | the app and `recommend` preselect the deployable-only bundle (it sorts first; it has no validated selective threshold, so it always gives the model's choice — confirmation −0.081 [−0.150, −0.026] against SBS-B); the frozen bundle is one click away and is the configuration the confirmation evaluated as primary |
| **Whether the 1.6.0 pilot data stay in the public archive** | `reports/selection_pilot/` | kept as the historical dataset (fixed-shared designs) beside the corrected pilot; its per-trial arrays and figures are omitted from the 1.7.0 source archive (size) and remain in the repository and the 1.6.0 archive | labelled historical in the app and in RESULTS |
